      <li>Project Description</li>
    </hr>
      <p>This project is a simple product card layout created using HTML and CSS. It displays different products in a grid format, similar to an online shopping website. Each product card contains a product image, category name, product name, original price, discounted price, sale label, discount percentage, and an Add to Cart button. The main purpose of this project is to learn how to design attractive product cards and arrange them properly on a webpage.</p>
    </hr>
      <li>What's included in this project</li>
    </hr>
      <ul>
        <li>Product Cards: Each product is displayed inside a separate box.</li>
        <li>Product Images: Images are added to show the products.</li>
        <li>Sale Label: A red label displays the sale information.</li>
        <li>Discount: A green box shows the discount percentage.</li>
        <li>Product Details: Category and product names are displayed.</li>
        <li>Price: Both original and discounted prices are shown.</li>
        <li>Add to Cart Button: A button is provided for adding products to the cart (visual design only).</li>
        <li>CSS Grid: Used to arrange product cards in rows and columns.</li>
        <li>CSS Styling: Used for colors, borders, spacing, alignment, and fonts.</li>
      </ul>
    </hr>
      <li>How this project is made</li>
    </hr>
      <p>This project is created using HTML and CSS. HTML is used to create the structure of the product cards, such as images, headings, prices, and buttons. CSS is used to style the cards by adding borders, background colors, spacing, rounded corners, and font styles. CSS Grid is used to arrange multiple product cards in rows and columns. Flexbox is used to align the prices and Add to Cart button properly. Google Fonts is also used to give the webpage a better font style.</p>
